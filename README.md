# 영단어 쑥쑥 🌱

초등학생용 영어 단어 암기 앱 (Words make you 단어장, 챕터별 약 60단어).

- 📖 단어 카드 (뒤집기, 발음 듣기)
- ✏️ 시험: 뜻 고르기 · 단어 고르기 · 뜻 쓰기 · 철자 쓰기 · 받아쓰기 · 섞어서
- 🎮 게임: 짝꿍 찾기 · 스피드 퀴즈 · 철자 퍼즐 · 풍선 터뜨리기
- 😥 오답 노트, 레벨·연속 학습일 기록 (브라우저에 저장)

## 단어 추가
`index.html` 상단 `BUILTIN_RAW` 에 챕터(ch2, ch3 …)를 추가하거나, 앱의 **단어장 관리**에서 `영어 = 뜻` 형식으로 붙여 넣으세요.
